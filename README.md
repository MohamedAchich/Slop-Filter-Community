# Slop Filter Community

[Slop Filter](https://mohamedachich.github.io/Slop-Filter-Community/) is a browser extension that hides or labels AI-generated videos on YouTube. It runs entirely in your browser.

This repository is where the community helps keep its shared list of AI channels accurate.

## Report an AI channel

The easiest way: in YouTube, hover a video from the channel, click **Flag as AI**, then **Report**. The form opens already filled in.

Or [open a report here](../../issues/new?template=report-ai-channel.yml).

A channel joins the shared list after **3 different people** report it and a maintainer reviews it. Reports from GitHub accounts younger than 30 days are not counted.

## A channel on the list isn't AI?

[Tell us](../../issues/new?template=dispute.yml) and we will review it.

## The shared list

[`site/blocklist.json`](site/blocklist.json), published at
`https://mohamedachich.github.io/Slop-Filter-Community/blocklist.json`.
Slop Filter Pro downloads it twice a day.

## Privacy

Slop Filter collects no data. Reports are public GitHub issues that you submit yourself.
Read the [privacy policy](https://mohamedachich.github.io/Slop-Filter-Community/privacy.html).
